# Empório Bão da Roça 🌾

Site oficial do **Empório Bão da Roça**, desenvolvido em HTML e CSS com foco em uma estética **premium rústica**, transmitindo tradição, afeto e desejo de compra.

O projeto foi criado para apresentar o empório, divulgar seus produtos artesanais e facilitar o contato direto com clientes via WhatsApp e Instagram.

---

## 📌 Visão Geral

O Empório Bão da Roça valoriza os sabores da roça, produtos artesanais e produtores locais.  
Este site funciona como uma **landing page institucional e comercial**, ideal para:

- Divulgação no Instagram (link da bio)
- Anúncios pagos
- Apresentação do empório para novos clientes
- Acesso rápido ao cardápio online

## 🚀 Como Publicar no GitHub Pages

1. Faça o upload do arquivo `index.html` neste repositório
2. Vá em **Settings > Pages**
3. Selecione a branch `main` e a pasta `/root`
4. Salve as configurações
5. Acesse o link gerado pelo GitHub Pages
